# Telegram Mini App - Чат-бот с искусственным интеллектом

Этот проект представляет собой чат-бот с искусственным интеллектом, интегрированный в Telegram Mini App.

## Особенности
- Интеграция с моделью Mixtral 8x7B через DeepInfra API
- Оптимизирован для русского языка
- Адаптирован для работы как Telegram Mini App
- Имеет запасные ответы на случай недоступности API

## Инструкция по настройке

### Шаг 1: Развертывание веб-приложения
1. Нажмите на кнопку "Deploy" в верхнем меню Replit
2. Введите имя для вашего проекта
3. Выберите опцию "Web Service"
4. Завершите процесс развертывания
5. **Сохраните полученный URL** (например, `https://имяпроекта.username.repl.co`)

### Шаг 2: Настройка Telegram бота
1. Создайте нового бота у [@BotFather](https://t.me/BotFather) в Telegram
2. Получите токен бота
3. Откройте файл `telegram_bot.py` и замените следующие значения:
   - `BOT_TOKEN = "твой_токен"` - на полученный токен бота
   - `permanent_url = "https://ваш-постоянный-домен.repl.co"` - на URL, полученный после развертывания

### Шаг 3: Запуск бота и веб-приложения
1. Запустите Replit-проект
2. **Веб-сервер и Telegram-бот теперь запускаются автоматически** при старте проекта
3. Откройте вашего бота в Telegram и отправьте команду `/start`
4. Нажмите на кнопку "Открыть чат с ИИ", которая появится в сообщении

### Важно: Работа после перезапуска
* После перезапуска Replit-проекта **бот запускается автоматически**, вам не нужно запускать его вручную
* Если бот не отвечает:
  1. Проверьте, запущен ли проект на Replit
  2. Проверьте логи запуска бота в консоли Replit
  3. При необходимости перезапустите проект через интерфейс Replit

### Как проверить работу бота
* Отправьте боту любую из доступных команд:
  - `/start` - начать работу с ботом
  - `/help` - получить справку
  - `/about` - информация о боте

## Важные файлы проекта
- `main.py` - Основной Flask-сервер с логикой чат-бота и API обработчиком (включает автоматический запуск бота)
- `static/index.html` - Интерфейс чат-бота для Telegram Mini App
- `static/js/chat.js` - JavaScript-код для обработки чата на стороне клиента
- `bot_test.py` - Тестовый скрипт для проверки работы Telegram API

## Дополнительные файлы (для отдельного запуска)
- `telegram_bot_launcher.py` - Альтернативный скрипт для запуска Telegram бота отдельно (не требуется для обычной работы)
- `integrated_app.py` - Экспериментальная версия интегрированного приложения
- `wsgi.py` - Точка входа для альтернативного запуска через Gunicorn

## Переменные окружения
- `DEEPINFRA_API_KEY` - API ключ для DeepInfra (необходим для работы с моделью Llama 3)
- `TELEGRAM_BOT_TOKEN` - Токен Telegram бота (необходим для работы бота)
